# Docker среда для экспериментов (долгоживущая)

Эта директория - **отдельная сущность** внутри `01-wr-rd/`.

Принцип:
- Образ строится **только при первом запуске** или при явном вызове `rebuild-if-needed.sh` (коордиальные изменения зависимостей)
- Контейнер `gst-meta-test` создаётся один раз и живёт
- Исходники монтируются bind-mount в `/work` (весь репозиторий) - компиляция идёт внутри контейнера, результаты видны с хоста
- Рабочие скрипты экспериментов лежат в `01-wr-rd/experiment/`

## Использование
```bash
# из корня репозитория или из любой директории
./01-wr-rd/docker/up.sh

# выполнить команду
./01-wr-rd/docker/exec.sh bash -lc "cd /work/01-wr-rd && ./build.sh"

# или в эксперименте
./01-wr-rd/docker/exec.sh bash -lc "cd /work/01-wr-rd/experiment/baseline/src && ./build.sh"

# оболочка
./01-wr-rd/docker/shell.sh
```
