# Docker среда для экспериментов (долгоживущая)

Эта директория - **отдельная сущность**. 

Принцип:
- Образ строится **только при первом запуске** или при явном вызове `rebuild-if-needed.sh` (коордиальные изменения зависимостей)
- Контейнер `gst-meta-test` создаётся один раз и живёт. При последующих запусках только стартует.
- Исходники монтируются bind-mount в `/work` - компиляция идёт внутри контейнера, результаты видны с хоста.
- Исходники не копируются внутрь образа, только монтируются.

## Использование
```bash
# первый раз / поднять
./docker/up.sh

# выполнить команду в контейнере
./docker/exec.sh bash -lc "cd /work/01-wr-rd && ./build.sh"

# интерактивная оболочка
./docker/shell.sh

# ребилд только если меняли Dockerfile/зависимости
./docker/rebuild-if-needed.sh
```
